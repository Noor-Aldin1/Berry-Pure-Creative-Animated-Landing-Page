Milk Template Documentation

Version 1.0.0 • Pure HTML5 / CSS3 / JavaScript • English (LTR) + Arabic (RTL)

1. Overview & Tech Stack

Milk is a premium, high-impact creative website template designed specifically for smoothie shops, juice bars, artisanal ice cream parlors, and modern dessert brands.

Built with zero required build tools or Node dependencies, the template runs directly in any modern browser while delivering smooth GSAP-driven micro-interactions, full bilingual support (English LTR and Arabic RTL), and a unified product catalog.

Technologies Used

  • Semantic HTML5 — Accessible, SEO-optimized markup with structured schema and meta descriptions.
  • Vanilla CSS3 — Clean custom properties (CSS variables), CSS Grid, and Flexbox for rapid color and style customization without Tailwind or preprocessors.
  • Vanilla JavaScript (ES6+) — Modular, lightweight scripts for sliders, filtering, searching, mobile drawer navigation, and language switching.
  • GSAP 3.12.5 (GreenSock) — Industry standard animation engine powering the 3D bowl transitions, kinetic floating fruit elements, and smooth entrance reveals.
  • Font Awesome 6 Free — Scalable SVG web icons for clean visual cues.
  • Google Fonts — Curated typography pairing:
    • English: DM Sans (body, UI, badges) & Cormorant Garamond (elegant display headers).
    • Arabic: Cairo (modern display titles) & IBM Plex Sans Arabic (crisp, readable body copy).

2. How to Preview Locally

Because Milk is a static HTML5 template, you do not need to run complex installation scripts or build commands. You can preview it immediately using any of the following methods:

Method A: VS Code Live Server (Recommended)

  1. Open the Milk project folder in Visual Studio Code.
  2. Install the popular Live Server extension (by Ritwick Dey).
  3. Right-click on index.html (or index-ar.html) and select "Open with Live Server".
  4. Your default browser will launch at http://127.0.0.1:5500/index.html with automatic reload on changes.

Method B: Python Built-in Server

Open terminal or PowerShell inside the project directory and run:

# Python 3
python -m http.server 8000

# Open in your browser:
http://localhost:8000/index.html

Method C: Node.js (npx serve)

npx serve .
Tip: You can also double-click index.html directly to preview in your web browser. Running via a local HTTP server is recommended to ensure all image assets and scripts load without CORS restrictions.

4. Customizing Colors

All theme colors are managed through CSS Custom Properties at the top of assets/css/main.css. To re-skin the brand or individual flavor backgrounds, adjust the variables: 

:root {
  /* Brand Core */
  --ffy-primary: #C90035;       /* Signature Berry Red */
  --ffy-primary-dark: #8B0024;  /* Deep Strawberry Burgundy */
  --ffy-white: #FFFFFF;
  --ffy-dark: #1A1A1A;
  --ffy-gray-light: #F8F6F4;

  /* Flavor Background Gradients */
  --ffy-strawberry-in: #8B0024;
  --ffy-strawberry-out: #C90035;

  --ffy-blueberry-in: #1B2A5E;
  --ffy-blueberry-out: #28448C;

  --ffy-banana-in: #B38600;
  --ffy-banana-out: #E6AC00;

  --ffy-kiwi-in: #27662B;
  --ffy-kiwi-out: #3A8E3F;
}
Tip: Changing --ffy-primary will automatically update buttons, active navigation indicators, hover states, and accent labels throughout the entire website.

6. Editing Text & Pages

Every page is plain, semantic HTML. Text can be modified directly in any text editor:

  • Page Headings & Descriptions: Search for <h1>, <h2>, and <p class="ffy-section-body">.
  • Contact Information: Located in the footer columns across all pages (address, phone number, email, and opening hours).
  • FAQ Questions & Answers: In faq.html and faq-ar.html, edit the <button class="ffy-faq-question"> and <div class="ffy-faq-answer"> blocks.

8. GSAP Animations & Interactions

The interactive hero carousel is implemented in assets/js/main.js using GSAP timelines:

  • Multi-Input Navigation: The slider can be controlled via on-screen arrows (.ffy-prev, .ffy-next), mouse wheel scrolling, keyboard arrows (← / →), and mobile touch gestures (swipe left/right).
  • Layered Parallax: Floating fruit garnishes (.ffy-floater) animate at different speeds and rotations, providing a realistic 3D depth effect.
  • Live Filter & Search: In products.html, product cards filter instantly on keypress or category pill click with smooth CSS opacity/transform transitions.
  • Form Validation & Feedback: The contact form features real-time email regex validation and triggers an animated feedback toast notification (#ffy-toast) upon submission.

9. Responsive Breakpoints

Milk is thoroughly responsive across all modern display viewports:

Breakpoint Device Target Layout Behavior
> 1024px Desktop & Laptops Full floating pill navigation, expanded multi-column footer, large 600px hero bowl showcase.
768px – 1024px Tablets (iPad, etc.) Adjusted padding, 2-column grid for products, scaled-down hero fruit floaters.
< 768px Mobile Devices Hamburger drawer menu, single-column product lists, and a sticky bottom CTA ordering bar on product detail pages.
< 480px Small Smartphones Optimized touch targets, simplified font sizes, and full-width form inputs.

10. Language Switch & RTL Support

Milk features first-class Arabic support with native Right-to-Left (RTL) formatting.

How RTL is Implemented

  • Arabic pages have <html lang="ar" dir="rtl"> declared at the top.
  • Custom Arabic typography is loaded via Google Fonts (Cairo and IBM Plex Sans Arabic).
  • Navigation order, logo alignment, and flex layouts mirror automatically without layout distortion.

Automatic Bidirectional Language Switch (syncLangLinks)

In assets/js/main.js, the syncLangLinks() function maps every English page directly to its corresponding Arabic equivalent and vice versa: 

// Page Mapping Registry in main.js
const PAGE_PAIRS = {
  'index.html': 'index-ar.html',
  'about.html': 'about-ar.html',
  'products.html': 'products-ar.html',
  'contact.html': 'contact-ar.html',
  'faq.html': 'faq-ar.html',
  '404.html': '404-ar.html',
  'product-berry-pure.html': 'product-berry-pure-ar.html',
  'product-blue-bliss.html': 'product-blue-bliss-ar.html',
  'product-banana-crush.html': 'product-banana-crush-ar.html',
  'product-kiwi-flavor.html': 'product-kiwi-flavor-ar.html'
};

When a user clicks the language switcher in the navbar or mobile menu, they are transitioned directly to the translated version of the exact page they are currently viewing.
